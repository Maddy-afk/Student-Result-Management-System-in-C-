# Student Result Management System in C++

This is a beginner-level C++ project that evaluates a student's academic performance based on marks entered by the user.

The program:
- Takes marks of 5 subjects as input
- Checks whether the student passed all subjects
- Counts failed subjects
- Calculates total marks
- Assigns grades based on total score

---

## Features

- Pass/Fail Detection
- Failed Subject Counter
- Grade Calculation System
- Function-Based Modular Design
- Uses Vectors and Loops
- Beginner-Friendly Logic

---

## Concepts Used

- Functions
- Vectors
- Loops
- Conditional Statements
- Pass by Reference
- Boolean Functions
- Basic Problem Solving

---

## Grade Criteria

| Total Marks | Grade |
|-------------|-------|
| Above 450   | A |
| Above 400   | B |
| Above 350   | C |
| Above 300   | D |
| 300 or below | E |

---

## Passing Criteria

- Marks below 33 are considered failed.
- Student must pass all subjects to receive a grade.
